# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-08-16

### Added

- Initial release with 40+ curated Flutter development extensions.
- 46 currently available Marketplace IDs in the installable extension pack manifest.
- Comprehensive catalog documenting all 50 requested IDs and their validation status.
- Flutter-inspired SVG and 256 by 256 PNG branding assets.
- GitHub issue templates, contribution guidance, Code of Conduct, and pull request template.
- GitHub Actions workflow for tagged Marketplace publication.
- Publishing guide, design decisions, recommended settings, shortcuts, and troubleshooting documentation.

### Changed

- No changes; this is the initial release.

### Deprecated

- None.

### Removed

- Four unavailable requested Marketplace IDs are documented but not placed in the installable manifest: `gornivv.vscode-flutter-helper`, `LottieFiles.lottiefiles`, `pflannery.vscode-find-unused`, and `jsayol.firebase-explorer`.

### Fixed

- None.

### Security

- No runtime code, telemetry, credentials, or secrets are included.
