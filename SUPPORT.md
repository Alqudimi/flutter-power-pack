# Support

Flutter Power Pack is a curated extension pack. Questions about Flutter SDK behavior, Dart analysis, or a specific bundled extension should be directed to the maintainer of that upstream tool after confirming which extension produced the behavior.

## Before opening an issue

Please update VS Code and Flutter Power Pack to the latest available version, confirm that the issue is reproducible with unrelated extensions disabled where practical, and search existing issues and discussions. Include the operating system, VS Code version, Flutter and Dart versions when relevant, the pack version, the affected bundled extension ID, reproduction steps, expected behavior, actual behavior, and a sanitized error log.

Never attach access tokens, passwords, private source code, customer data, or other confidential information. Security concerns must follow `SECURITY.md` rather than a public issue.

## Issue routing

Use the bug-report template for reproducible defects in this pack's manifest, release packaging, documentation, or automation. Use the feature-request template for additions or changes to the curated extension list. For an upstream extension's command, language service, UI, or crash, report the issue to that extension's own repository and include its exact ID.

## Compatibility note

The pack installs extensions from independent publishers. Their release schedules, licenses, platform support, account requirements, and compatibility constraints remain controlled by those publishers. A service extension may require its own account or subscription; installing this pack does not provide or endorse those services.
